# Product Backlog

**Project:** EcoCharge Fleet Dashboard (Prototype)
**Team:** Hamad, Mayed

| ID | User Story | Priority | Sprint |
|----|------------|----------|--------|
| US1 | As a manager, I want to see a list of all EVs and their battery levels so I can know which ones are ready to use. | High | Sprint 1 |
| US2 | As a manager, I want to see the status of each vehicle (Available, Charging, On Trip) so I know where every car is at right now. | High | Sprint 1 |
| US3 | As a manager, I want to pick a vehicle and enter how many hours it will charge so I can see the estimated charging cost. | High | Sprint 1 |
| US4 | As a manager, I want to get a clear error message if I type something wrong in the calculator so I don't get a wrong cost. | High | Sprint 1 |
| US5 | As a manager, I want to see a quick count of how many cars are available, charging and on trip so I can understand the fleet at one look. | Medium | Sprint 1 |
| US6 | As a manager, I want low battery cars to stand out with a different color so I can notice them fast. | Medium | Sprint 1 |
| US7 | As a manager, I want to filter or sort the fleet list by status or battery so I can find cars quicker. | Low | Future |
| US8 | As a manager, I want to see each vehicle on a live map so I know where it is. | Low | Future (needs privacy review, see ethics memo) |
| US9 | As a manager, I want to log in with my own account so only managers can see the fleet data. | Low | Future (see security memo) |
