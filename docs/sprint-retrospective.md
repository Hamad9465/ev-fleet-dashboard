# Sprint Retrospective (Sprint 1)

**Team:** Hamad, Mayed

## What went well

Splitting the work by feature worked really well for us. Hamad did the fleet overview and Mayed did the calculator, so we each had our own branch and we didn't step on each other's code. Using pull requests was helpful too, because reviewing each other's work made us actually read the code instead of just merging it. Writing the unit tests also caught a real bug, the calculator was showing "$NaN" when you typed letters, and we fixed it before the final version.

## What we would do differently

We waited too long to start the documents, so the memos and README got left to the last few days. Next time we would write them during the sprint. We also started the calculator branch only after the fleet branch was merged, which slowed things down a bit. Next time we would plan the files better so both features can be built at the same time. Short check ins every few days would also help.
