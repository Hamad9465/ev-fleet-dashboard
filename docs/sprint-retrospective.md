# Sprint Retrospective (Sprint 1)

**Team:** Hamad, Mayed

## What went well

Splitting the work by feature worked well. Hamad did the fleet overview and Mayed did the calculator, so we each had our own branch and didn't step on each other's code. Reviewing each other's pull requests made us actually read the code instead of just merging it. The unit tests also caught a real bug, the calculator showed "$NaN" when you typed letters, and we fixed it before the final version.

## What we would do differently

At first we copied whole folders into the repo instead of the files inside them, so the files ended up in the wrong place and `index.html` wasn't at the top. We fixed it with a refactor commit, but next time we'd check the repo on GitHub after every push. We also left the documents for the last few days, and Hamad ended up with more tasks than Mayed. Next sprint we'd split the work more evenly.
